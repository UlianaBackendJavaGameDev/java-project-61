Brain Games

Brain Games is a set of five console-based math games developed as part of the Hexlet curriculum. Each game presents the user with three questions. To win, the player must answer all three questions correctly in a row.
Prerequisites

    Java: 21 or higher

    Gradle: 8.x

Installation & Setup

    Clone the repository:
    Bash

    git clone https://github.com/YOUR_USERNAME/java-project-61.git
    cd java-project-61

    Build and install the project:
    Bash

    ./gradlew installDist

    Run the main application:
    Bash

    ./build/install/brain-games/bin/brain-games
